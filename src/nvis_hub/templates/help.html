Using the hub

Find documentation across NVIS - OVA projects, then read it here. Each page links back to the exact revision in its source repository.

Find a procedure

Use global search for a tool, phrase, or command. Results show matching sections and excerpts. Choose a project, topic, or document type when that metadata is available. Search uses authored text; it does not generate answers.

Read with context

Choose a project to follow its documentation. Navigation follows the source’s curated table of contents when supported; otherwise it is generated from the published files. The page contents list links to individual headings. Long code blocks scroll within the reading column.

Register and refresh

From the project directory, activate the environment and register a JSON configuration that declares the repository, branch, and documentation paths:

source .venv/bin/activate
nvis-hub register sources/cluster-bringup.json
nvis-hub refresh cluster-bringup
nvis-hub list

Review docs/how-to/register-and-refresh.md and docs/reference/configuration.md for registration fields and private-source credentials. A snapshot registration imports verified local source bytes. A live registration fetches the configured GitLab ref. Registration and refresh are explicit commands.

Connect an agent

The hub’s MCP server exposes project discovery, ranked search, and document or section retrieval from the same publication used by this website.

nvis-hub --db data/hub.sqlite3 mcp

Configure your MCP client to launch this command with the hub directory as its working directory, or supply absolute paths. Available tools are list_projects, search_documents, and get_document. See docs/reference/mcp.md for an example and the verification command.

Source ownership

Maintain documentation in its original repository. The hub publishes selected documentation and supported attachments. See source status for current revisions, publication times, and import errors.
